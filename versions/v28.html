Sample / Base Shader Template

          
Download a ready-to-import .gsgshader template containing complete formatting instructions (_instructions) and working shader code you can modify and load back in.

          

            
            
          

          

            Quick formatting guide
            

              
    
                
  • Single shader or pack: Set "format": "godot-shader-generator-shader" and "version": 1. Put fields at the top level for one shader, or wrap multiple shaders in "shaders": [ ... ].
    • 
                
  • Categories: "Surface", "Vertex shaders", "Water & liquids", "Post-processing", "Volumetric", or "Screen effects".
    • 
                
  • Parameters (params): Sliders (min, max, step, value), colors ("type": "color", "#rrggbb"), toggles ("type": "toggle"), and dropdowns ("type": "select", "options": [...]). Optional showIf accepts an object ({"no_base_color": false}) or expression ("!no_base_color && mode == 'A'").
    • 
                
  • Code templates: Use {{UNIFORMS}}, {{TEXTURES}}, {{HELPERS}}, {{RENDER_MODES}}, {{param_id}}, and {{#if expr}}...{{else}}...{{/if}}. Raw GDShader code without tokens also works—declared uniforms are synced with sliders automatically.
    • 
                
  • Helper kits (helpers): "noise3d", "hash2d", "hsv", "triplanar", "water_depth", "water_screen".
    • 
                
  • Combine mode: Set "combinable": true (default for Surface, Vertex, Water, Screen). Use ctx.combined and ctx.hasBase in {{#if}} blocks, and add a no_base_color toggle for overlay blending. For combinable Screen effects, put vec3 effect(vec2 uv, vec3 base) in "layerCode".
